| OD-01 | Does the plan carry expected bytes? | A: form + operands + choices only; B: plus optional expected bytes/hash; C: full byte template + explicit patch fields | One vertical slice per ISA built under A and B; measure plan size, verifiability, and whether B catches real definition drift | AC-04, AC-07 | **accepted 2026-11-04: variant B, hash only.** `EXP-0002` measured 92 B per instruction (+21.4 % over A). ## Decision procedure

1. Build the smallest experiment that distinguishes the options.
2. Record the measurement in `research/evidence/experiments/`.
3. Accept with an ADR if the decision changes an architecture boundary; otherwise
   mark the row `accepted` here with a one-line rationale.
4. Superseding an accepted row requires a new ADR reference in the same row.
