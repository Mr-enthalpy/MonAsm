Bit 31 is 0 (`adr`), `immlo` holds the low two bits of the
signed 21-bit byte displacement and `immhi` bits 2-20. The
last three rows are symbols: 0, -24 and -8 bytes away, so the
reference point is the instruction address, not its end.

adr/adrp contrast (`EC-43`), same split, bit 31 apart:

Row 1 is the clean pair: the same zeros under `adr` and
`adrp` differ only in bit 31. Row 3 states 4096 bytes and
lands as page delta 1, so one shared row would have to read
the number to know whether it means bytes or pages.
